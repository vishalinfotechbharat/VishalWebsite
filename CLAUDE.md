# Frontend Rules

Stack:
- React + Vite
- JavaScript only
- module.scss only
- No Tailwind
- No TypeScript

Styling Rules:
- Always use separate module.scss files
- Always use classname={styles.className}
- Use variables.scss globally
- Mobile-first responsive design
- Enterprise SaaS quality UI

UI Rules:
- Premium spacing system
- Modern typography hierarchy
- Smooth animations
- Accessibility optimized
- Reusable architecture
- Production-ready code only

Animation:
- Use Framer Motion
- Minimal modern motion
- Avoid flashy effects

Code:
- No duplicate logic
- Reusable components
- Clean folder structure
